100% EXTERNAL COMPANION APP:
- Modifies ZERO IL-2 binary or .gtp game files (multiplayer integrity-check safe).
- Reads your real IL-2 keybinds from data\input\current.actions / global.actions.
- Note for Telemetry Haptics: On first run, the app adds [KEY = motiondevice]
  and [KEY = telemetrydevice] to IL-2's data\startup.cfg (saving a backup at
  data\startup.cfg.bak_il2vr). Restart IL-2 once after this first setup.

--------------------------------------------------------------------------------
[ENGLISH] STEP-BY-STEP QUICK START
--------------------------------------------------------------------------------

STEP 1 - Install Prerequisites
  1. Windows 10/11 (64-bit) with SteamVR / OpenVR working (Meta Quest 3 via
     Quest Link, Air Link, Virtual Desktop, or Steam Link).
  2. Install vJoy (Device 1 enabled):
     https://github.com/BrunnerInnovation/vJoy/releases
  3. Enable all vJoy axes (X, Y, Z, Rz + buttons):
     - Right-click "repair_vjoy_axis.bat" -> Run as Administrator (once), OR
       use the red button inside the VR HUD if missing axes are detected.

STEP 2 - Launch Order (IMPORTANT)
  1. Double-click "initiate_il2_vr_qol_mod.bat" from Windows Explorer.
     (Must be launched on your normal Windows desktop session so VR Menu Mouse
     and IL-2 keybinds can send events into IL-2).
  2. Start SteamVR and put on your Quest 3 headset.
  3. Start "IL-2 Sturmovik: Great Battles" in VR mode.
     - If IL-2 was ALREADY open before the companion patched data\startup.cfg,
       close IL-2 and open it once more so UDP telemetry starts streaming.

STEP 3 - Essential Quest 3 Controls (Global Default Profile)
  Companion Utility Commands (Complex inputs so X/Y/A/B stay 100% free!):
  * 3x L3 (Triple-click LEFT thumbstick)  : Show / Hide the floating VR HUD
  * 3x R3 (Triple-click RIGHT thumbstick) : Toggle Flight Mode <-> Edit 3D Origin
  * Hold L3 (0.65s)                       : Recenter VR cockpit seat on your head
  * Hold R3 (0.65s)                       : Toggle VR Raycaster Mouse in IL-2 Menus
  * Hold RIGHT / LEFT Grip                : 6DoF Virtual Stick / Throttle Lever

  Main Aircraft & Combat Commands (X, Y, A, B freed for IL-2!):
  * RIGHT Trigger (Hold)    : Fire All Guns (vJoy Btn 1)
  * RIGHT A (Hold / 2x / Hold 0.5s) : Cannons Group 2 (vJoy 2) / Drop Bombs (B) / Rockets (R)
  * RIGHT B (1x / 2x / Hold 0.6s)   : Landing Gear (G) / Airbrakes (RAlt+B) / Canopy (RAlt+C)
  * RIGHT A + B Together            : Reload All Guns (LAlt+R)
  * LEFT Trigger (Hold)             : Wheel Brakes (vJoy Btn 3)
  * LEFT X (1x / 2x)                : Flaps Down (F) / Flaps Up (LShift+F)
  * LEFT Y (1x / Hold 0.6s)         : Parking Brakes (LShift+/) / Engine Start-Stop (E)
  * LEFT X + Y Together (Hold 0.65s): Bail Out / Eject (LCtrl+E - accidental-safe!)
  * LEFT Trigger + RIGHT A Together : Bomb Bay Doors Toggle (N)

STEP 4 - Keybinds Editor, Multiple Profiles & 3D Controller Map
  * Open the HUD (3x L3) and click "Controls & Keybinds Editor (Profiles)".
  * "Global Default (Immutable)" is read-only; click "Clone Global Now" to
    save custom profiles in config\profiles\ and rebind any button or 2-button
    combo using live "Capture VR".
  * Toggle "Show 3D Controller Callout Map" in the HUD to display glowing pins
    on your Quest 3 controller buttons with 1 or 2 lines connecting to clear,
    non-overlapping floating labels explaining each binding & gesture!

--------------------------------------------------------------------------------
[PORTUGUES BR] GUIA RAPIDO PASSO A PASSO
--------------------------------------------------------------------------------

PASSO 1 - Pre-requisitos e Ordem para Abrir
  1. Instale o vJoy (Device 1 ativo). Se precisar, clique direito em
     "repair_vjoy_axis.bat" -> Executar como Administrador uma vez.
  2. De duplo clique em "initiate_il2_vr_qol_mod.bat" pelo Windows Explorer.
  3. Abra o SteamVR e o "IL-2 Sturmovik: Great Battles" (reinicie o IL-2 uma
     unica vez apos a primeira execucao caso ele ja estivesse aberto).

PASSO 2 - Comandos no Quest 3 (Padrao Global Imutavel)
  Comandos do Companion (Complexos p/ liberar X, Y, A e B ao aviao!):
  * 3x L3                : Abre / Fecha o HUD VR
  * 3x R3                : Alterna Modo Voo <-> Editar Origem 3D
  * Segurar L3 (0.65s)   : Recentraliza o assento na sua cabeca
  * Segurar R3 (0.65s)   : Liga / Desliga Mouse VR nos Menus do IL-2
  * Segurar Grip Dir/Esq : Manche 6DoF / Manete Travada

  Principais Comandos do Aviao (X, Y, A, B livres!):
  * Gatilho Dir                : Metralhadoras / Todas as Armas (vJoy 1)
  * Botao A Dir (Seg/2x/0.5s)  : Canhoes (vJoy 2) / Soltar Bombas (B) / Foguetes (R)
  * Botao B Dir (1x/2x/0.6s)   : Trem de Pouso (G) / Airbrake / Canopy
  * A + B Dir Juntos           : Recarregar Armas (LAlt+R)
  * Gatilho Esq                : Freios das Rodas (vJoy 3)
  * Botao X Esq (1x / 2x)      : Baixar Flaps (F) / Recolher Flaps (LShift+F)
  * Botao Y Esq (1x / 0.6s)    : Freio Estac. / Ligar-Desligar Motor (E)
  * X + Y Esq Juntos (0.65s)   : Pular / Ejetar (LCtrl+E)
  * Gatilho Esq + A Dir Juntos : Portas do Compartimento de Bombas (N)

PASSO 3 - Editor de Keybinds, Perfis & Mapa Visual 3D
  * Clique em "Editor de Controles & Keybinds (Perfis)" no HUD para clonar o
    Padrao Global Imutavel e personalizar qualquer comando com "Capturar VR".
  * Ative "Mostrar Mapa Visual 3D nos Controles VR" para ver linhas ligando
    cada botao fisico ate tarjas explicativas sem sobreposicao!
